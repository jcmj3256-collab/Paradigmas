Java genera archivos .jar, es un zip, que genera instrucciones por medio de un bytecode,  
que va a ejecutar una maquina virtual, que para ejecutarse necesita JVM o Java Virtual Machine,  
por lo que se puede ejecutar en cualquier computadora o dispositivo que tenga el JVM, Kotlin y  
Grooby tambien pueden ser ejecutados en la JVM ya que son compilados por el bytecode. Se necesita  
el JDK para trabajar en java, OpenJDK.

No es recomendable VSC para Java, mejor usar IntelliJ(IDEA)
