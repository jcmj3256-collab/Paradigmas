# Paradigmas

# ✅ Mi checklist de progreso

> Regla de oro: no paso al siguiente tema hasta poder hacer el anterior **sin ver la solución**.
> Ritmo: 2 sesiones/semana de estructuras de datos + 1 de paradigmas (30-60 min).

## 🧠 Paradigmas de programación

### ⭐⭐⭐ Programación orientada a objetos
- [ ] Clase con atributos, métodos y constructor
- [ ] Encapsulamiento (privado/público)
- [ ] Asociación, agregación y composición
- [ ] Herencia simple
- [ ] Clases abstractas e interfaces
- [ ] Polimorfismo
- [ ] Manejo de excepciones (y crear una propia)
- [ ] Mini proyecto: sistema de biblioteca o figuras geométricas

### ⭐⭐ Programación funcional
- [ ] Funciones puras vs. con efectos secundarios
- [ ] Expresiones lambda
- [ ] `map`, `filter`, `reduce`
- [ ] Composición de funciones
- [ ] Recursión sobre listas
- [ ] Evaluación estricta vs. perezosa (lazy)

### ⭐⭐ Programación lógica (Prolog)
- [ ] Hechos y consultas
- [ ] Reglas
- [ ] Árbol genealógico
- [ ] Reglas recursivas (ancestros)

### ⭐ Eventos y servicios (conceptual)
- [ ] Patrón Modelo-Vista-Controlador
- [ ] Programación orientada a eventos
- [ ] Arquitectura orientada a servicios / microservicios
